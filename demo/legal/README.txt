DEMO — Sector Legal
===================

Antes de la reunión:
1. Copiá 1-3 contratos reales (anonimizados) a esta carpeta como .pdf o .txt
2. Corré:  python chat.py --demo legal
           python web.py --demo legal

Durante la demo:
- CLI:  el cliente ve la terminal en tu pantalla
- Web:  compartí la pantalla mostrando http://localhost:7860

Para limpiar entre clientes:
  python chat.py  →  /list  →  /delete <nombre> por cada documento
